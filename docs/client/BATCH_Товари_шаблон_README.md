# Як заповнити `BATCH_Товари_шаблон.csv`

Один рядок — один товар. Колонки, які стосуються тільки кави (країна, нотки, метри),
для аксесуарів/подарунків/млинків залишай порожніми — все опційне.

**Як відкрити:** Google Sheets / Numbers / Excel. Збережи назад у форматі **CSV (UTF-8)**.

**Фото:** не вставляй у таблицю. Збирай у папку з назвами на кшталт `ethiopia-sidamo-1.jpg`,
`ethiopia-sidamo-2.jpg` — і шли разом з CSV. Я завантажу їх у Sanity і прив'яжу до slug'а.

## Опис колонок

### Обов'язкові

| Колонка | Опис | Приклад |
|---|---|---|
| `slug` | URL-адреса товару, латиницею через дефіси, **унікальна** | `ethiopia-sidamo`, `drip-house-blend` |
| `name` | Назва на сайті | `Ефіопія Сідамо` |
| `category` | Категорія — рівно одне з: `beans` / `ground` / `drip` / `capsules` / `gear` / `grinders` / `gifts` | `beans` |
| `shortDescription` | Однорядковий опис під назвою на картці. До 120 символів | `Ягідна й квітуча — лот з натуральною обробкою.` |

### Опційні (загальне)

| Колонка | Опис | Приклад |
|---|---|---|
| `story` | Довгий опис на сторінці товару, кілька речень | `Лот з ферми на висоті 1 950 м у Сідамо…` |
| `badge` | Бейдж на картці — одне з: `Новий` / `Bestseller` / `Limited`. Порожньо = без бейджа | `Новий` |
| `inStock` | `TRUE` або `FALSE`. Якщо порожньо — вважається `TRUE` | `TRUE` |

### Походження (тільки для кави — `beans` / `ground` / `drip` / `capsules`)

| Колонка | Опис | Приклад |
|---|---|---|
| `origin` | Коротко для хлібних крихт | `Сідамо, Ефіопія` |
| `country` | Країна | `Ефіопія` |
| `region` | Регіон | `Сідамо` |
| `process` | Обробка — одне з: `Мита` / `Натуральна` / `Інф'юз` / `Бленд` | `Натуральна` |
| `altitude` | Висота, як хочеш писати | `1 950 м` |
| `varietal` | Сорт | `Heirloom`, `Caturra`, `Bourbon`… |
| `farm` | Назва ферми | `Sidama Coffee Farmers Co-op` |
| `harvest` | Коли зібрано | `Січень 2026` |

### Смак (тільки для кави)

| Колонка | Опис | Приклад |
|---|---|---|
| `notes` | Смакові ноти, **до 5 штук**, розділяй знаком `\|` | `Полуниця \| Чорний чай \| Мед` |
| `acidity` | Кислотність 1-5 | `4` |
| `sweetness` | Солодкість 1-5 | `4` |
| `bitterness` | Гіркота 1-5 | `2` |
| `roasts` | Профілі обсмажки, через `\|`. Доступні: `Фільтр`, `Еспресо`, `Універсальна` | `Фільтр \| Еспресо` |
| `grinds` | Опції помелу, через `\|`. Доступні: `Не молоти`, `Еспресо`, `V60`, `Аеропрес`, `French Press`, `Moka` | `Не молоти \| Еспресо \| V60` |

### Варіанти ваги і ціни

Заповнюй тільки ті, які реально продаєш. Якщо немає 1 кг — залиш `price_1kg` порожнім.

| Колонка | Опис | Приклад |
|---|---|---|
| `price_250g` | Ціна за 250 г, грн | `420` |
| `price_500g` | Ціна за 500 г, грн | `790` |
| `price_1kg` | Ціна за 1 кг, грн (потрібна для розрахунку **гуртової ціни** при 3+ кг) | `1490` |

> Для дріпів, капсул, аксесуарів — пиши ціну у `price_250g` як єдину ціну упаковки, інші залишай порожніми. Або скажи в чаті як назвати «вагу» (напр. «6 шт») — додам нову колонку.

### Фото

| Колонка | Опис |
|---|---|
| `gallery` | Залиш порожнім. Шли файли окремо, я прив'яжу. |

5. Якщо щось треба поправити вручну — можна через Sanity Studio (`/studio` на сайті)
