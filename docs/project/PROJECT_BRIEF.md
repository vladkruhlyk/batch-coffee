# BATCH Coffee Roastery — общая сводка проекта

## 1. Что делаем

Интернет-магазин кофе ростерии с подпиской, на уровне [onelove.ua](https://onelove.ua/). 16 разделов по ТЗ: каталог, корзина, чекаут, личный кабинет, подписка, Brew Guide, About, FAQ и т.д.

## 2. Стек

| Слой | Технология | Зачем |
|---|---|---|
| **Frontend** | Next.js 15 (App Router) + TypeScript | Скорость, SEO, красивый UI |
| **Стили** | Tailwind CSS + CSS variables | Быстрая верстка, брендинг через переменные |
| **Анимации** | Framer Motion + GSAP + Lenis (smooth scroll) | Уровень onelove.ua |
| **State** | Zustand (корзина, UI) + React Query (серверные данные) | Минимум бойлерплейта |
| **Формы** | React Hook Form + Zod | Валидация, типобезопасность |
| **Auth** | NextAuth.js + JWT | Безопасно, стандарт |
| **Backend / CMS** | WordPress + WooCommerce | Админка, товары, заказы, юзеры |
| **API** | WPGraphQL + WooGraphQL | Связь фронта с WP |
| **Платежи** | LiqPay + Monobank Acquiring | Украинский рынок |
| **Доставка** | Nova Poshta API | Автоподстановка городов/отделений |
| **Подписка** | WooCommerce Subscriptions (плагин) | Автосписания |
| **Поиск** | WooCommerce search → Algolia (если >500 товаров) | Мгновенный поиск |
| **Email** | SendGrid / Mailgun | Транзакционные письма |
| **Хостинг фронта** | Vercel | Быстрый, бесплатный старт |
| **Хостинг бэка** | Hostinger Business / Ukraine.com.ua | Дешёвый надёжный WP-хостинг |
| **Аналитика** | GA4 + Meta Pixel + Hotjar | Цифры + поведение юзеров |
| **Мониторинг** | Sentry (ошибки) + UptimeRobot (uptime) | Чтоб узнавать о поломках раньше юзеров |

## Детали по архитектуре

### Как работает связка WordPress + Next.js

```
┌─────────────────┐         ┌──────────────────────┐
│   Next.js       │  HTTP   │   WordPress + Woo    │
│   (фронт)       │ ◄────► │   (бэкенд / админка) │
│   Vercel        │  JSON   │   VPS                │
└─────────────────┘         └──────────────────────┘
        │                              │
        │                              ├── MySQL (товары, заказы, юзеры)
        │                              ├── Nova Poshta API
        │                              └── LiqPay / Monobank
        │
        ├── Cookies / localStorage (корзина гостя)
        ├── NextAuth (сессия залогиненного юзера)
        └── React state (UI)
```

**Принцип:** WordPress — это «база данных с админкой». Next.js — это «витрина». Они общаются через GraphQL API.

### Как работает личный кабинет

**WordPress/WooCommerce даёт готовое:**
- Таблица юзеров, хэширование паролей, сессии
- Система ролей (customer, shop manager, admin)
- Заказы со статусами (pending → processing → completed)
- Подписки (через плагин) — автопродление, пауза, отмена
- Password reset, email verification
- Бэк-офис для менеджера

**Мы (Next.js) пишем только UI:**
- Красивые формы (регистрация, логин, профиль)
- Layout кабинета
- Карточки заказов и подписок
- Модалки подтверждения
- Анимации, toast-уведомления
- Мобильная адаптация

Все данные — запросами в WooCommerce через GraphQL. WordPress фронт не используется вообще.

### Структура роутов Next.js

```
/                     → Home
/shop                 → Каталог
/shop/[slug]          → Карточка товара
/cart                 → Корзина
/checkout             → Оформление
/order/success        → Thank You
/account              → Кабинет
/account/orders
/account/orders/[id]
/account/subscriptions
/account/addresses
/account/profile
/subscription         → Лендинг подписки
/about
/delivery
/contacts
/brew-guide
/brew-guide/[method]
/faq
/compare
/404
```

### Как работает checkout

1. Юзер на `/checkout` → Next.js рендерит форму
2. Город/отделение НП подтягивается через **Nova Poshta API** напрямую из Next.js
3. Жмёт «Підтвердити» → Next.js шлёт мутацию `createOrder` в Woo
4. Woo создаёт заказ со статусом `pending`, возвращает ID
5. Next.js редиректит на LiqPay/Mono с суммой и order_id
6. Юзер платит → банк делает callback на WP webhook
7. WP меняет статус заказа на `processing`, шлёт email
8. Юзер возвращается на `/order/success?id=XXX` — Next.js показывает Thank You

1. Купить домен (namecheap.com, ukraine.com.ua, hostpro.ua) — $10–30/год
