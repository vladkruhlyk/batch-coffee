# BATCH Coffee — інструкція для клієнта

Все що потрібно зробити з вашого боку, щоб довести сайт до запуску.
Розбито на блоки за пріоритетом. Те що **🔴 критично** — без цього
сайт фізично не може запрацювати в повну силу. Решта — за бажанням
або коли буде час.

## 🔴 Критично перед запуском

### 1. Власний домен

Без свого домену сайт живе на тимчасовій адресі `batch-coffee.vercel.app`.
Для запуску потрібен ваш домен (напр. `batch.coffee` або
`batchcoffee.ua`).

**Що зробити:**

- Купити домен на REG.ua / GoDaddy / Namecheap (~$10-15/рік)
- Передати нам логін/пароль або просто доступ до DNS-налаштувань
  (краще другий варіант)
- Ми пропишемо A-запис на Vercel і налаштуємо SSL

### 2. ФОП + бойові ключі WayForPay

> **Стан:** WayForPay уже підключено у тестовому режимі. Можна тестувати
> оплату прямо зараз — на чекауті оберіть «Картка онлайн» і використайте
> тестову карту `4444 5551 1111 6666`, `12/25`, CVV `123`. Реальні гроші
> не списуються. Для запуску в проді потрібні бойові ключі.

**Чому WayForPay:**

- Інтегрується швидше за LiqPay (простіша підпис-схема)
- Підтримує Apple Pay / Google Pay з коробки
- Конкурентна комісія (~2.5% залежно від обороту)
- Apple/Google Pay + рекурентні платежі для підписки

**Що зробити для production:**

1. Зареєструвати ФОП (якщо ще ні)
2. Створити обліковий запис на [wayforpay.com](https://wayforpay.com)
3. Завести магазин у кабінеті WayForPay
4. Передати нам:
   - `merchantAccount` (логін магазину, напр. `batch_coffee_pl`)
   - `merchantSecret` (секретний ключ)
   - Підтвердити `merchantDomainName` = реальний домен сайту
5. (Опціонально) шаблон договору-оферти

**Якщо потрібен LiqPay або Monobank замість WayForPay** — теж можемо
переключити, але треба переробити інтеграцію.

### 3. Реальний контент каталогу

Сайт зараз має тестові товари. Перед запуском потрібно завантажити
**ваш реальний каталог**.

**Що потрібно для кожного товару:**

- Назва кави (напр. «Ефіопія Сідамо Гедео»)
- Походження: країна, регіон, ферма/кооператив, висота, сорт,
  обробка (натуральна / мита), дата збору
- Опис / story (1-2 абзаци про лот, чому він особливий)
- Смакові ноти (3-5 тегів: «Полуниця, Чорний чай, Мед»)
- Профіль обсмажки: фільтр / еспресо
- Кислотність / Солодкість / Гіркота (по 5-бальній шкалі)
- Ціни для варіантів: 250г / 500г / 1кг
- Фото: 3-5 шт на товар (1200×1200, JPG/PNG, чистий фон або
  лайфстайл)

**Куди завантажувати:**

- Самостійно через адмінку Sanity Studio (надамо доступ)
- Або скиньте нам в Telegram/Drive — заллємо самі за окрему годину
  роботи

## 🟡 Важливо, але не блокує запуск

### 5. Доставка Новою Поштою

Без API-ключа доставка працює напіввручну: клієнт сам пише адресу
відділення, ви руками створюєте ТТН в кабінеті НП і вписуєте номер
у нашу адмінку. Робить, але повільніше.

**Що дає API-ключ:**

- Автокомплеіт «оберіть відділення» прямо на чекауті
- Автоматичне створення ТТН після підтвердження замовлення
- Трекінг доставки на сторінці замовлення для клієнта

**Що зробити:**

1. Зайти на [novaposhta.ua](https://novaposhta.ua), створити
   бізнес-кабінет (якщо ще нема)
2. У кабінеті: Налаштування → API → згенерувати ключ
3. Передати нам ключ

### 6. Email-сповіщення

Зараз клієнт не отримує лист «Дякуємо за замовлення», ви не
отримуєте «Новий заказ!». Все ведеться вручну через адмінку
сайту.

**Найпростіший варіант — Resend:**

- 3000 листів/місяць безкоштовно (вистачить надовго)
- Готові красиві шаблони
- Підключається за 30 хв

**Що зробити:**

1. Зареєструватись на [resend.com](https://resend.com)
2. Додати домен (той самий що для сайту)
3. Передати нам API-ключ

**Альтернативи:** SendGrid, Mailgun, власний SMTP.

### 7. SMS-логін

Зараз клієнт може зайти тільки через email. SMS-логін зручніший
для українського ринку (не всі мають email під рукою).

**Провайдер — TurboSMS** (популярний в Україні):

- ~0.30 ₴ за SMS
- Передплата, поповнюєте баланс наперед
- API простий

**Що зробити:**

1. Зареєструватись на [turbosms.ua](https://turbosms.ua)
2. Закинути на баланс хоча б 100 ₴ для тестів
3. Передати нам API-токен і альфа-ім'я (відправник, напр. «BATCH»)

### 8. Чат-віджет

Потрібно вирішити: **через який месенджер** ви хочете спілкуватись
з клієнтами на сайті?

- **Telegram** — найзвичніший в Україні, ви бачите всі чати в
  одному місці, гарно для одного оператора
- **WhatsApp Business** — для туристів та діаспори
- **Viber** — найменш популярний, не рекомендую
- **Inline-чат** (типу Crisp / Tidio) — повноцінна служба підтримки
  з історією, аналітикою

**Що зробити:**

Дайте відповідь у форматі: «Хочу X» і скиньте посилання на
канал/контакт.

## 🟢 Бажано, але можна після запуску

### 9. Google Аналітика + Meta Pixel

Без аналітики не видно скільки людей заходить, звідки приходять,
що купують. Краще підключити **до** запуску, щоб з першого дня
збиралась статистика.

**Що зробити:**

1. Google Analytics 4 — створити обліковий запис на
   [analytics.google.com](https://analytics.google.com), отримати
   `Measurement ID` (виглядає як `G-XXXXXXXXXX`)
2. Meta (Facebook) Pixel — створити пиксель у Business Manager,
   отримати `Pixel ID` (16-значне число)
3. Передати нам обидва ID

### 10. Google таблиця складу

Зараз залишки треба правити прямо в Sanity Studio. Якщо команда
хоче вести склад у Google Таблиці (зручніше для бариста /
постачальника) — можемо синхронізувати.

**Що зробити:**

1. Створити Google таблицю з колонками:
   - `slug` (унікальний код товару)
   - `stock_kg` (залишок у кг)
2. Дати нам доступ на читання (поділитись з email
   сервіс-акаунта — надамо)
3. Скинути посилання

Раз на 15 хвилин сайт буде підтягувати остатки. «Нема в
наявності» — автоматично.

### 11. Domain email

Якщо хочете щоб з адреси `hello@batch.coffee` справді приходила
пошта (не тільки відображалась) — налаштувати MX-записи на
Gmail / Google Workspace / Zoho. **$6/міс** за Google Workspace,
або безкоштовно через [Zoho Mail](https://zoho.com/mail).

## ❓ Питання на які треба відповісти

Без цих відповідей не можемо рухатись далі:

1. **Програма лояльності** — як саме вона працює?
   - 1 ₴ = 1 бал?
   - Скільки балів = яка знижка?
   - Чи можна списати всі бали одразу, чи є ліміт?
   - Бали згоряють через час?
2. **Підписка на каву** — які періоди?
   - Раз на 2 тижні / місяць / квартал?
   - Знижка для підписників — скільки %?
   - Чи може клієнт пропустити доставку?
3. **Доставка** — коли безкоштовна?
   - Зараз стоїть «від 800 ₴» — підтверджуєте чи інша сума?
4. **Самовивіз** — як працює?
   - Готова кава за 1-2 години після обсмажування — підтверджуєте?
5. **Повернення** — політика?
   - Згідно ЗУ можна повернути протягом 14 днів якщо упаковка
     не пошкоджена. Чи погоджуєтесь з такою політикою?
